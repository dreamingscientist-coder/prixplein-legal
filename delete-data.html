Supprimer mes données

Pour effacer les données locales, désinstallez l’application. Avant cela, désactivez vos alertes si vous ne souhaitez plus de surveillance.

Pour supprimer les données serveur liées aux alertes ou contributions, contactez dreamingscientist@gmail.com. Précisez la version de l’application et les stations ou dates concernées. Ne transmettez jamais de clé API, de jeton de notification ou de secret d’installation par e-mail. Nous vous guiderons pour identifier les données concernées.

Contact : dreamingscientist@gmail.com
