Comment utiliser PrixPlein

  1. Recherchez une ville, une adresse ou un code postal, ou utilisez votre position.
  2. Sélectionnez un carburant ou une prise de recharge. Les filtres limitent les résultats.
  3. Touchez une station pour consulter les prix. Ajoutez-la aux favoris avec le cœur.
  4. Choisissez le départ et la destination avec le bouton de trajet. Comparez les alternatives et les stations proches ; effacez le trajet pour revenir à la carte locale.
  5. Ouvrez Itinéraire pour choisir Apple Maps, Google Maps ou Waze.
  6. Signalez un prix ou un stock seulement si vous l’avez observé. Demander un rapport sollicite la communauté, pas l’exploitant.
  7. Dans Alertes, choisissez vos préférences et autorisez les notifications. Les alertes automatiques officielles couvrent actuellement les favoris carburants en France.

Badges

Les diamants et badges indiquent l’activité de contribution, sans valeur monétaire ni garantie de fiabilité. Touchez le bouton d’information du badge pour voir les seuils.

Données manquantes

Les prix peuvent être retardés ou absents. Les horaires publiés ne sont pas une mesure d’affluence en direct. Les tarifs de recharge ne sont pas toujours disponibles.
